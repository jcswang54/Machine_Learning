# AI Financial Research Assistant

An end-to-end AI system for querying and analyzing SEC filings using Retrieval-Augmented Generation (RAG).

## Project Goals

- SEC filing ingestion
- Document chunking
- Semantic embeddings
- Vector database retrieval
- LLM-powered answers with citations
- FastAPI backend
- Streamlit frontend
- Evaluation of retrieval and answer quality
- Agentic financial research workflows

## Architecture

SEC Filings → Chunking → Embeddings → Vector Database → Retrieval → LLM → Cited Answer
